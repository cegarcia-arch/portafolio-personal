# Portafolio personal de Cesar Garcia

Estudiante: Cesar Leonardo Garcia Macias.

Portafolio en desarrollo para la Actividad Integradora 1 de Programación de Sistemas Web. Presentará información personal, habilidades, ejercicios y un formulario visual de contacto.

## Tecnologías utilizadas

- HTML para organizar el contenido.
- CSS para aplicar los estilos.
- Git y GitHub para registrar los avances y compartir el proyecto.

## Cómo visualizarlo

1. Descargar la carpeta del proyecto.
2. Abrir `index.html` en un navegador.

No necesita instalación de paquetes ni conexión a una base de datos.

Para editarlo con Phoenix Code, abrir la carpeta completa del proyecto y seleccionar `index.html` o `styles.css`.

## Archivos

- `index.html`: estructura y contenido de la página.
- `styles.css`: estilos externos.
- `img/`: imágenes del portafolio. Por ahora contiene `avatar.svg`, una imagen provisional con las iniciales CG.

## Estado del avance

Tercera etapa: se añadieron el texto de Sobre mí y cuatro tarjetas de habilidades con etiquetas `article`. Las tarjetas utilizan Flexbox para distribuirse según el espacio disponible. El menú conserva sus cinco enlaces internos, el efecto `:hover` y los colores definidos como variables dentro de `:root`.

Las habilidades propuestas son gestión de fibra óptica, mantenimiento de infraestructura, organización de tareas y trabajo en equipo. El texto personal y las habilidades son un borrador para que Cesar revise que describen su experiencia, sus intereses y sus objetivos.

Todavía faltan los proyectos y el formulario de contacto. La fotografía y la información sobre estudios están pendientes. Este avance no es la entrega final.
