# Portafolio personal de Cesar Garcia

Estudiante: Cesar Leonardo Garcia Macias.

Portafolio en desarrollo para la Actividad Integradora 1 de Programación de Sistemas Web. Presentará información personal, habilidades, ejercicios y un formulario visual de contacto.

## Tecnologías utilizadas

- HTML para organizar el contenido.
- CSS para aplicar los estilos.
- Git y GitHub para registrar los avances y compartir el proyecto.

## Repositorio público

https://github.com/cegarcia-arch/portafolio-personal

## Cómo visualizarlo

1. Descargar la carpeta del proyecto.
2. Abrir `index.html` en un navegador.

No necesita instalación de paquetes ni conexión a una base de datos.

Para editarlo con Phoenix Code, abrir la carpeta completa del proyecto y seleccionar `index.html` o `styles.css`.

## Archivos

- `index.html`: estructura y contenido de la página.
- `styles.css`: estilos externos.
- `img/`: fotografía de Cesar e imágenes de los proyectos. La página utiliza `cesar-garcia.png` para la presentación, `vista-portafolio.jpg` para el portafolio y `fibra-optica.jpg` para el trabajo de mantenimiento.

## Estado del avance

Proyectos tiene dos tarjetas con imagen, título y descripción breve. Se muestran en una fila cuando hay espacio y se colocan una debajo de otra en una pantalla estrecha. Contacto contiene un formulario visual de ancho limitado. Se tomó como referencia la sencillez de la página compartida por el usuario, sin reutilizar los datos personales ni las imágenes del otro estudiante.

Las habilidades propuestas son gestión de fibra óptica, mantenimiento de infraestructura, organización de tareas y trabajo en equipo. El texto personal y las habilidades son un borrador para que Cesar revise que describen su experiencia, sus intereses y sus objetivos.

La fotografía fue proporcionada por el usuario. La información sobre estudios y la revisión final están pendientes. El repositorio ya está publicado en GitHub.

## Proyectos

1. Mi portafolio personal: corresponde a esta página con presentación, habilidades y contacto.
2. Mantenimiento preventivo de fibra óptica: actividad anual orientada a conservar la infraestructura en buen estado y contribuir a su correcto funcionamiento.

El segundo elemento describe una actividad laboral relacionada con fibra óptica, según la información proporcionada por el usuario, no una aplicación informática. El portafolio es una página de HTML y CSS sin JavaScript ni base de datos.

El formulario de Contacto es únicamente visual. El botón Enviar mensaje es de tipo button y no transmite mensajes ni valida los campos al pulsarlo.

PCCS significa Pacific Caribbean Cable System y se refiere a un sistema de cable submarino. Referencia del nombre y de su estación de amarre en Manta: https://www.arcotel.gob.ec/la-coordinacion-zonal-4-de-la-arcotel-rindio-cuentas-a-la-ciudadania-en-portoviejo/
