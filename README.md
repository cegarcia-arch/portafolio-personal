# Mi portafolio personal

Mi nombre es Cesar Leonardo Garcia Macias. En esta página presento mi experiencia en fibra óptica, mis habilidades y mi interés por aprender desarrollo web. El portafolio corresponde a la Actividad Integradora 1 de Programación de Sistemas Web.

## Contenido

Organicé la información en cinco secciones: Inicio, Sobre mí, Habilidades, Proyectos y Contacto. Incluí mi fotografía y dos tarjetas: una sobre este portafolio y otra sobre el mantenimiento preventivo anual de la infraestructura de fibra óptica.

El formulario de contacto tiene campos para nombre, correo y mensaje. Es una demostración visual y no envía información.

## Tecnologías

- HTML para estructurar la página.
- CSS para definir los colores, los espacios y la distribución.
- Git para guardar los cambios y GitHub para compartir el proyecto.

## Cómo abrirlo

1. Descargar el repositorio y descomprimirlo.
2. Abrir `index.html` en un navegador.

No necesita instalar paquetes. Para editarlo en Phoenix Code, se abre la carpeta completa y se selecciona el archivo que se desea modificar.

## Archivos

- `index.html`: contiene los textos y las secciones.
- `styles.css`: contiene los estilos.
- `img/`: guarda mi fotografía y las imágenes de los proyectos.
